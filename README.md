# InterLink GitHub Pages Front-End

A self-contained static recreation inspired by the public structure of `p2p-interlink.com`.

## Deploy on GitHub Pages

1. Create a new GitHub repository, for example `p2p-interlink`.
2. Upload `index.html` and this `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/root`, then save.
6. GitHub will provide the Pages address for the repository.

## Important

This project is a front-end demo. It intentionally does not collect seed phrases, private keys, passwords, card numbers, or other sensitive wallet credentials. Replace branding, legal text, partner claims, and product claims with information you can verify and are authorized to publish.

For a production P2P marketplace, add a real backend for authentication, listings, orders, escrow, dispute handling, notifications, KYC/AML where legally required, rate limiting, audit logging, and security monitoring.
